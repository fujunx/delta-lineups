# Delta Lineups

《三角洲行动》道具点位教学库，用于在实战中快速查询地图、干员和对应的道具点位。

项目计划以纯静态单页应用实现，无需后端或数据库。正式版本可部署到 GitHub Pages，也可以在本地启动开发服务使用。

## 当前状态

项目处于需求与技术方案确认阶段，尚未开始业务代码开发。

已确定的首期范围：

- 地图：大坝、航天
- 干员：露娜、威龙
- 默认查询：航天 + 露娜
- 点位内容：一句话用途、带开始时间的 B 站视频、1～4 张有序步骤图
- 主要目标分辨率：3440×1440、2560×1440
- 内容由 AI 录入和维护

完整方案与开发约定见 [开发文档](./docs/DEVELOPMENT.md)。
